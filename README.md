# Portafolio Personal

## Estudiante
Johanna Barragán

## Descripción
Sitio web estático que funciona como portafolio personal. Presenta información
básica, habilidades, proyectos desarrollados y una sección de contacto. El diseño
utiliza una paleta inspirada en los colores de marca de LinkedIn.

## Tecnologías utilizadas
- HTML5 con etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 con variables en `:root`, Flexbox y pseudoclase `:hover`
- Git y GitHub para el control de versiones

## Instrucciones para visualizar el proyecto
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/usuario/portafolio-johanna-barragan.git
   ```
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en cualquier navegador web.

También puede visualizarse en línea mediante GitHub Pages.
